Click-to-Call starts a call from your own software. TalkChief first rings the member you name, then connects them to the destination number. Use it to put a call button in a CRM, a helpdesk or an internal tool, with no dialing in the TalkChief app.

<Note>
  The member must be online on a TalkChief device and not already on a call. Otherwise the request fails with `error_code` 415 or 416.
</Note>

## Before you start

<Steps>
  <Step title="Get the Click-to-Call key">
    As a company admin, go to **Settings** → **Integrations** → **API Keys**. On the **Click-to-Call** panel, click **Generate key** if you don't have one yet. Then click **Copy**. See [Authentication](/developers/authentication).
  </Step>
  <Step title="Decide how to identify the member">
    You can identify the member who places the call by email address or by extension.
  </Step>
</Steps>

## Place a call

```text
POST https://api.talkchief.io/public/api/calls/click-to-call
```

You can send the body as JSON or as form fields. The limit is 300 requests per minute.

### Request

<ParamField body="api_key" type="string" required>
  Your 64-character Click-to-Call key. You can send it in the `X-API-Key` header instead. If both are present, the body value wins.
</ParamField>

<ParamField body="destination" type="string" required>
  The number to dial, with the country code. TalkChief removes every character except digits, `,` and `.`. At least 9 characters must remain.
</ParamField>

<ParamField body="email" type="string">
  Email address of the member who places the call. You must send `email` or `extension`. If you send both, TalkChief uses `email` and ignores `extension`.
</ParamField>

<ParamField body="extension" type="string">
  Extension of the member who places the call, up to 4 digits. Only used when you don't send `email`.
</ParamField>

<ParamField body="auto_answer" type="string" default="true">
  Set to `true` to ring the member's desk phone and answer it automatically. If that phone can't take the call, the member's devices ring normally. Set to `false` to ring all of the member's devices. The value must be exactly `true` or `false`. A JSON boolean also works.
</ParamField>

<ParamField body="custom_param" type="object">
  Key/value pairs that come back in the response, such as your CRM record ID. TalkChief adds `call_id` to this object.
</ParamField>

<ParamField body="custom_params" type="any">
  Any value. It comes back unchanged in the response.
</ParamField>

### Example

<CodeGroup>

```bash curl
curl -X POST 'https://api.talkchief.io/public/api/calls/click-to-call' \
  -H 'Content-Type: application/json' \
  -d '{
    "api_key": "YOUR_CLICK_TO_CALL_KEY",
    "destination": "15555550123",
    "email": "agent@yourcompany.com",
    "auto_answer": "true",
    "custom_param": { "crm_record_id": "12345" }
  }'
```

```python Python
import os
import requests

resp = requests.post(
    "https://api.talkchief.io/public/api/calls/click-to-call",
    json={
        "api_key": os.environ["TALKCHIEF_C2C_KEY"],
        "destination": "15555550123",
        "email": "agent@yourcompany.com",
        "auto_answer": "true",
        "custom_param": {"crm_record_id": "12345"},
    },
    timeout=30,
)
if resp.status_code == 429:
    # Rate limited before the request was processed: back off and retry
    raise RuntimeError("Rate limited, retry later")
resp.raise_for_status()  # any other non-200 status
body = resp.json()  # processed requests return HTTP 200
if body["success"]:
    call_id = body["data"]["custom_param"]["call_id"]
else:
    print(body["error_code"], body["message"], body.get("errors"))
```

</CodeGroup>

### Response

<ResponseField name="success" type="boolean">
  `true` when TalkChief placed the call.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="email" type="string">The email you sent, in lowercase, or an empty string.</ResponseField>
    <ResponseField name="extension" type="string">The extension you sent, or an empty string.</ResponseField>
    <ResponseField name="destination" type="string">The destination after cleanup.</ResponseField>
    <ResponseField name="custom_param" type="object">Your `custom_param`, plus `call_id`, the platform ID of the call. TalkChief adds `call_id` even when you send no `custom_param`.</ResponseField>
    <ResponseField name="custom_params" type="any">Your `custom_params`, unchanged, or `null`.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="message" type="string">
  An empty string when the call succeeds.
</ResponseField>

```json 200 OK
{
  "success": true,
  "data": {
    "email": "agent@yourcompany.com",
    "extension": "",
    "destination": "15555550123",
    "custom_param": {
      "crm_record_id": "12345",
      "call_id": "example-call-id"
    },
    "custom_params": null
  },
  "message": ""
}
```

Store `call_id` so you can match the call to your CRM record later.

## Errors

Click-to-Call returns **HTTP 200** for every request it processes. When a request fails, the body has `success: false`, a numeric `error_code`, a `message` and an `errors` object:

```json
{
  "success": false,
  "error_code": 413,
  "message": "Validation Error.",
  "errors": { "api_key": "api_key is invalid." }
}
```

| `error_code` | Text | Meaning |
|---|---|---|
| 404 | `auto_answer value error.` | `auto_answer` isn't `true` or `false` |
| 405 | `api_key is required.` | You didn't send a key |
| 406 | `api_key is invalid.` | The key isn't 64 characters |
| 407 | `destination is required.` | You didn't send a destination |
| 408 | `destination is invalid` | Fewer than 9 characters remain after cleanup |
| 409 | `At least email or extension is required.` | You sent neither `email` nor `extension` |
| 410 / 412 | `email format is not correct.` | `email` isn't a valid address |
| 411 | `extension is invalid.` | The extension is 5 digits or longer |
| 413 | `api_key is invalid.` | The key doesn't match a company. It may have been rotated |
| 414 | `Either email or extension is invalid` | No member in your company has that email address or extension |
| 415 | `User is not Registered. Please check your network` | The member has no device online. This text is in `message` |
| 416 | `User is busy.` | The member is already on a call. This text is in `message` |
| 417 | Varies | The TalkChief phone platform rejected the call. Details are in `errors.error_message_detail` |
| 418 | `telephony service unavailable` | A temporary platform problem. Retry with backoff. The text is in `errors.error_message_detail` |

For errors 404 to 414 and 418, `message` is `Validation Error.` and the text is in `errors`. For 415 and 416, the text is in `message`. For 417, `message` holds the platform's reason (or `call failed`) and `errors.error_message_detail` holds the detail.

## Tips

- Run the request from your server so the key never reaches a browser.
- If you get 415, ask the member to sign in to the TalkChief app or desk phone and try again. If you get 416, wait until their current call ends.
- To track the call after it ends, set up the [CDR webhook](/developers/webhooks). It sends a call record when the call finishes.
