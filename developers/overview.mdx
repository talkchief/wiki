TalkChief has three integration points for developers. You can start calls from your CRM or website, send call recordings to be transcribed, and receive a record of every completed call at your own endpoint. Company admins set all three up in the TalkChief app under **Integrations** (the **API** and **CDR Webhook** tabs).

## What you can build

| Integration | What it does | How it authenticates |
|---|---|---|
| [Click-to-Call](/developers/click-to-call) | Rings one of your members, then connects them to the number you send. | Click-to-Call API key in the request body (`api_key`) or the `X-API-Key` header |
| [AI Transcription API](/developers/transcription-api) | Transcribes a recording at an HTTPS URL. The transcript is split by speaker. | AI Transcriber API key in the `X-AI-Api-Key` header, plus your `company_id` |
| [CDR webhook](/developers/webhooks) | Sends a call detail record (CDR) to your endpoint after each call ends. | Optional credential that you choose: bearer token, basic auth or a custom header |

## Base URL

All API requests go to the base URL shown in **Integrations** → **API** → **Overview & keys**:

```text
https://api.talkchief.io/public/api
```

For example, Click-to-Call is `POST https://api.talkchief.io/public/api/calls/click-to-call`.

## Where to manage everything

Open **Integrations** in the TalkChief app menu. The page has three tabs:

- **CRM**: connect HubSpot, Zoho, Pipedrive and the other CRM integrations.
- **CDR Webhook**: the destinations that receive a record of every completed call, plus the payload reference.
- **API**: everything for the developer APIs, in four sections:
  - **Overview & keys**: the base URL, your **Company ID**, and the **Click-to-Call** and **AI Transcriber** keys (generate, show, copy, rotate).
  - **Click-to-Call** and **AI Transcription**: reference material.
  - **OpenAPI Spec**: download the specification with **Download JSON** or **Download PDF**.

Click-to-Call, AI Transcription and the CDR webhook used to be under **Settings** → **Integrations**. Old links to that page open **Integrations** → **API**.

<Note>
  Only company admins can view, generate or rotate API keys and change the webhook settings.
</Note>

<Warning>
  API keys can place calls and spend your wallet balance. Keep them in your backend configuration. Never put them in browser code, mobile apps or source control.
</Warning>
