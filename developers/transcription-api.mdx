The AI Transcription API turns a call recording into text. Each part of the transcript is labeled with its speaker and timing. You send the URL of the recording and get back a transcription ID. Then you poll that ID until the transcript is ready.

<Note>
  This API is separate from [automatic AI transcription](/ai/ai-transcription), the add-on that transcribes your TalkChief calls for you. The API transcribes any recording you send it, and each job is billed from your wallet.
</Note>

## How it works

1. You submit a recording with `POST /ai/transcriptions` and get back HTTP `202` with a `transcription_id`.
2. You poll `GET /ai/transcriptions/{transcription_id}` until `status` is `completed` or `error`.
3. When the job completes, the response contains the full `text`, the speaker-labeled `utterances` and the `billed_amount`.

<Warning>
  There's no webhook or callback for transcriptions. Poll for the result, or send `wait` to hold the submit request open for up to about 50 seconds.
</Warning>

## Before you start

<Steps>
  <Step title="Get the AI Transcriber key">
    As a company admin, go to **Integrations** → **API** → **Overview & keys**. On the **AI Transcriber** panel, click **Generate key** if you don't have one yet, then click **Copy**.
  </Step>
  <Step title="Copy your Company ID">
    The **Company ID** appears at the top of the same page. Send it as `company_id` on every submit request.
  </Step>
  <Step title="Top up your wallet">
    Your wallet must hold at least the minimum balance before you submit. If it doesn't, the request fails with HTTP `402`.
  </Step>
</Steps>

Send the key in the `X-AI-Api-Key` header on every request. Both endpoints allow 120 requests per minute.

## Submit a recording

```text
POST https://api.talkchief.io/public/api/ai/transcriptions
```

<ParamField header="X-AI-Api-Key" type="string" required>
  Your AI Transcriber key.
</ParamField>

<ParamField body="company_id" type="integer" required>
  Your Company ID. It must belong to the same company as the key, otherwise you get HTTP `403`.
</ParamField>

<ParamField body="recording_url" type="string" required>
  A public `https://` URL of the audio file, up to 1,024 characters. The URL must stay reachable while the job runs.
</ParamField>

<ParamField body="language" type="string">
  A language hint such as `en`, `ar` or `he`, up to 16 characters. If you leave it out, the language is detected automatically. When detection finds a language, it replaces your hint in the result.
</ParamField>

<ParamField body="detect_language" type="boolean" default="true">
  Set to `true` to identify the languages spoken. Send `false` to turn detection off. Accepts `true`/`false`, `1`/`0` or `"true"`/`"false"`.
</ParamField>

<ParamField body="detect_audio_events" type="boolean" default="false">
  Set to `true` to mark sounds such as laughter or music in the transcript. Off by default.
</ParamField>

<ParamField body="wait" type="boolean">
  Send `1` to wait for the result in a single request, for up to about 50 seconds. You can send it in the body or as a query parameter (`?wait=1`). If the job is still running when time is up, you get back the normal pending response. Keep polling that ID.
</ParamField>

Language detection and audio event detection don't cost extra.

<CodeGroup>

```bash curl
curl -X POST 'https://api.talkchief.io/public/api/ai/transcriptions' \
  -H 'X-AI-Api-Key: YOUR_AI_TRANSCRIBER_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "company_id": 1234,
    "recording_url": "https://example.com/recordings/call.mp3",
    "language": "en"
  }'
```

```python Python
import os
import time
import requests

BASE = "https://api.talkchief.io/public/api"
HEADERS = {"X-AI-Api-Key": os.environ["TALKCHIEF_AI_KEY"]}

submit = requests.post(
    f"{BASE}/ai/transcriptions",
    headers=HEADERS,
    json={
        "company_id": 1234,
        "recording_url": "https://example.com/recordings/call.mp3",
    },
    timeout=60,
)
submit.raise_for_status()  # expect 202
job_id = submit.json()["data"]["transcription_id"]

while True:
    poll = requests.get(f"{BASE}/ai/transcriptions/{job_id}", headers=HEADERS, timeout=30)
    data = poll.json()["data"]
    if data["status"] in ("completed", "error"):
        break
    time.sleep(4)

if data["status"] == "completed":
    for u in data["utterances"]:
        print(f'[{u["speaker"]}] {u["text"]}')
else:
    print("Failed:", data["error"])
```

</CodeGroup>

```json 202 Accepted
{
  "success": true,
  "data": {
    "transcription_id": "3f1c2b9e-8a41-4d6f-9a0e-2b7c5d1e4f60",
    "status": "queued",
    "audio_duration_ms": null,
    "language": "en"
  },
  "message": null
}
```

Save `transcription_id` before you start polling.

<Warning>
  Never submit the same recording again because a request timed out. Each submission is a new job that's billed on its own. Poll the ID you already have instead.
</Warning>

## Get the result

```text
GET https://api.talkchief.io/public/api/ai/transcriptions/{transcription_id}
```

<ParamField path="transcription_id" type="string" required>
  The `transcription_id` from the submit response.
</ParamField>

<ParamField header="X-AI-Api-Key" type="string" required>
  Your AI Transcriber key. You can only read transcriptions that belong to your own company.
</ParamField>

Poll every 3 to 5 seconds until `status` is `completed` or `error`. Polling is free. Once a transcript is complete it's stored, so you can fetch it again any time.

<CodeGroup>

```bash curl
curl 'https://api.talkchief.io/public/api/ai/transcriptions/3f1c2b9e-8a41-4d6f-9a0e-2b7c5d1e4f60' \
  -H 'X-AI-Api-Key: YOUR_AI_TRANSCRIBER_KEY'
```

```javascript Node.js
const res = await fetch(
  "https://api.talkchief.io/public/api/ai/transcriptions/3f1c2b9e-8a41-4d6f-9a0e-2b7c5d1e4f60",
  { headers: { "X-AI-Api-Key": process.env.TALKCHIEF_AI_KEY } }
);
const { data } = await res.json();
console.log(data.status, data.text);
```

</CodeGroup>

```json 200 OK
{
  "success": true,
  "data": {
    "transcription_id": "3f1c2b9e-8a41-4d6f-9a0e-2b7c5d1e4f60",
    "status": "completed",
    "audio_duration_ms": 56232,
    "language": "en",
    "languages": ["en"],
    "text": "Thanks for calling, how can I help you? Hi, I'd like to check my order.",
    "utterances": [
      { "speaker": "1", "start_ms": 570, "end_ms": 2010, "text": "Thanks for calling, how can I help you?" },
      { "speaker": "2", "start_ms": 2400, "end_ms": 4300, "text": "Hi, I'd like to check my order." }
    ],
    "billed_amount": 0.015
  },
  "message": null
}
```

### Response fields

<ResponseField name="success" type="boolean">
  `false` only when `status` is `error`.
</ResponseField>

<ResponseField name="data.transcription_id" type="string">
  The job ID (a UUID).
</ResponseField>

<ResponseField name="data.status" type="string">
  One of `queued`, `processing`, `completed` or `error`.
</ResponseField>

<ResponseField name="data.audio_duration_ms" type="integer | null">
  Length of the audio in milliseconds, once it's known.
</ResponseField>

<ResponseField name="data.language" type="string | null">
  The main language detected. If nothing was detected, this is your `language` hint.
</ResponseField>

<ResponseField name="data.languages" type="string[]">
  Every language detected, with the most spoken first. Only present when languages were detected.
</ResponseField>

<ResponseField name="data.text" type="string">
  The full transcript. Only present when `status` is `completed`.
</ResponseField>

<ResponseField name="data.utterances" type="object[]">
  The transcript split by speaker. Only present when `status` is `completed`. Each item has `speaker`, `start_ms`, `end_ms` and `text`. Speaker labels tell voices apart within one recording. They don't say which speaker is the agent or the customer.
</ResponseField>

<ResponseField name="data.billed_amount" type="number">
  The amount in USD charged for this job. Only present when `status` is `completed` and the charge has gone through.
</ResponseField>

<ResponseField name="data.error" type="string">
  Only present when `status` is `error`. For example: "The recording could not be processed. Check that the URL is reachable and points to a supported audio file."
</ResponseField>

## Billing

- Each completed transcription is charged to your company wallet per minute of audio. The current rate is shown in **Integrations** → **API** → **AI Transcription**.
- Every job is billed for at least one minute. After the first minute, billing is per second, so a 26-second recording is billed as 60 seconds and a 73-second recording as 73 seconds.
- Jobs that end in `error` aren't charged.
- Before TalkChief accepts a job, your wallet must hold the minimum balance. If it doesn't, you get HTTP `402` with `Error balance is below $5, please topup to proceed`, and nothing is submitted or charged.
- To check your balance, call `GET /ai/billing/balance` with the same `X-AI-Api-Key` header. The response has `company_id` and `balance` (a string with 5 decimal places).

## Errors

| HTTP status | `message` | What to do |
|---|---|---|
| `400` | `Validation Error.` | A field is missing or malformed. Check `errors` for details |
| `400` | `recording_url must be an https URL` | Use an `https://` URL |
| `401` | `UnAuthorised` | Check the `X-AI-Api-Key` header. The key may have been rotated |
| `402` | `Error balance is below $5, please topup to proceed` | Top up your wallet |
| `403` | `company_id does not match the provided token` | Send the Company ID that belongs to this key |
| `404` | `transcription not found` | Check the ID. You can only read your own company's jobs |
| `502` | `billing system unavailable` or `transcription service unavailable` | Temporary. Retry with backoff |

A job that fails after it was accepted still returns HTTP `200` when you poll. The response has `success: false`, `status: "error"` and an `error` message.
