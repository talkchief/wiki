Your phone numbers live in **Calls** → **Numbers**. From there you buy numbers, name them, give them to teams, and open their call flows. Caller ID is set per team, with an override for each member.

<Note>
  Buying, assigning, renewing, and releasing numbers are admin-only. Supervisors can view numbers and their details and rename them.
</Note>

## Buy a number

<Steps>
  <Step title="Start the purchase">
    Go to **Calls** → **Numbers** and select **Buy number**. The **Buy a New Number** dialog opens.
  </Step>
  <Step title="Choose the type and location">
    Under **What type of number do you need?**, pick a **Type**, such as **Local**, **Mobile**, or **Toll-free**. The types on offer depend on the country. Then choose a **Country** and, where asked, a **State** and **City**. Leave **Any city** to search the whole country.
  </Step>
  <Step title="Check availability">
    Select **Check Availability**. TalkChief shows a **Number Available** card with the **One-time setup fee** and the **Monthly Cost**.
  </Step>
  <Step title="Submit registration details if asked">
    Some countries show **Registration Required**. Before you can use the number, you must provide proof of a local address and a valid ID. Fill in the required fields, choose a **Document Type**, and select **Upload Document**. Each file can be up to 2 MB. Select **Next** to continue.
  </Step>
  <Step title="Assign and name the number">
    Under **Who will be using this number?**, pick a team. Under **what would you like to name this number?**, enter a **Nickname**, such as "Main line". Confirm the purchase.
  </Step>
</Steps>

<Tip>
  If no number shows up for a city, try another city or leave **Any city** selected.
</Tip>

## Manage your numbers

Each number appears as a card with its nickname, status, and assigned team. Use the search box (**Search number, name or team**) and the status filters (**All**, **Active**, **Pending**, **High spam**) to find one.

Open a number's actions menu to:

| Action | What it does | Who can use it |
|---|---|---|
| **Details** | Shows the **Type**, **Monthly Price**, **Next Billing Cycle**, **Purchase Date**, and **Spam Score**. | Admin, supervisor |
| **Rename** | Changes the **Nickname**. | Admin, supervisor |
| **Assign teams** | Adds or removes teams for this number. One team is marked **Default**. | Admin |
| **Callflow** | Opens the number's call flow. See [Call flows](/phone/call-flows). | Admin |
| **Renew** | Requests renewal of a number that is being removed. | Admin |
| **Release** | Releases the number. You type the number's name to confirm. | Admin |

<Warning>
  Releasing a number stops calls to it. Check that the number isn't printed on your website or materials before you release it.
</Warning>

## Assign numbers to a team

You can also manage numbers from the team's page.

<Steps>
  <Step title="Open the team">
    Go to **Team** → **Teams & Members**, then select **Manage Team** on the team card.
  </Step>
  <Step title="Add numbers">
    Open the **Numbers** tab and select **Assign Numbers**. Pick the numbers to add and select **Assign**.
  </Step>
  <Step title="Choose the default number">
    In a number's **Actions** menu, select **Make Default**. To take a number away from the team, select **Remove from this Team**.
  </Step>
</Steps>

## Set the caller ID

Caller ID is the number people see when your team dials out. You set it on each team's **Outbound** tab.

<Steps>
  <Step title="Open the team's Outbound tab">
    Go to **Team** → **Teams & Members**, select **Manage Team**, then open **Outbound**.
  </Step>
  <Step title="Choose the team default">
    Under **Default setting**, pick one option. Unavailable options are grayed out.
  </Step>
  <Step title="Override for a member if needed">
    Under **Member Settings**, set a member's **Caller ID** to **Custom**. Then choose a number under **Customized Caller ID**. Members left on **Default** show **Follows default team settings**.
  </Step>
  <Step title="Save">
    Select **Save**. Select **reset** to undo unsaved changes.
  </Step>
</Steps>

| Option | How it works |
|---|---|
| **Default Number** | Every call uses the team's default number. |
| **Random Number** | Each call uses a random number from the team's numbers. The team needs at least 3 numbers. We recommend at least 5. |
| **Dynamic Number** | TalkChief picks a team number that matches the country you dial. For example, a call to France uses a French number. If no number matches, it uses the team default. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why can't I select Random Number?">
    The team needs at least three assigned numbers. Assign more numbers on the team's **Numbers** tab, then try again.
  </Accordion>
  <Accordion title="Can a member always call from the same number?">
    Yes. On the team's **Outbound** tab, set the member's **Caller ID** to **Custom** and pick the number.
  </Accordion>
  <Accordion title="What does the High spam filter show?">
    It lists numbers flagged as high spam risk. Open **Details** to see the number's **Spam Score**.
  </Accordion>
</AccordionGroup>
