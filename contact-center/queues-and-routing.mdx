A call queue holds callers until an agent is free, then rings agents in the order you choose. Use queues when several people share the same calls, such as a support or sales line. This page is for admins who set up call routing.

<Note>
  Queues are managed in the admin workspace. The number of queues you can create depends on your plan. If you reach the limit, TalkChief shows an error when you create a new queue. See [Plans and pricing](/plans-and-pricing).
</Note>

## Before you start

- Upload your hold music in **Configuration** > **Media**. Every queue needs a media file.
- Invite the members who will take queue calls in **Team** > **Teams & Members**.

## Create a queue

<Steps>
  <Step title="Open Queues">
    In the sidebar, go to **Team** > **Queues**, then select **+ New Queue**.
  </Step>
  <Step title="Fill in the queue details">
    Under **Queue Details**, enter a **Queue Name** and an **Extension Number**. Then set the **Queue timeout (Max wait time)**, the **Queue SLA Threshold**, the **Time Zone**, and the **Media** file to play while callers wait. You can play the media file before you save.
  </Step>
  <Step title="Turn on position announcements (optional)">
    Select **Enable Position Announcement** to tell callers their place in the queue. Set the **Announcement Interval** and the **Announcement Language**.
  </Step>
  <Step title="Choose how agents ring">
    Under **Agent Details**, pick a **Ring Strategy**, then set the **Agent Wrap-up time** and how long to **Ring each agent for**.
  </Step>
  <Step title="Save the queue">
    Select **Create Queue**. The queue appears as a card on the **Queues** page.
  </Step>
</Steps>

## Queue settings

| Setting | What it does | Allowed values |
|---|---|---|
| **Queue Name** | The name agents and reports show. Must be unique. | Any unique name |
| **Extension Number** | The internal extension that reaches the queue | 1 to 9999 |
| **Queue timeout (Max wait time)** | The longest time a caller waits in the queue | 30 to 300 seconds, default 180 |
| **Queue SLA Threshold** | Your answer-time target for this queue | 30 seconds, 1 minute, 1.5 minutes, or 2 minutes |
| **Time Zone** | The time zone for the queue | Required |
| **Media** | Hold music or message played while callers wait | Required |
| **Enable Position Announcement** | Tells callers their place in the queue | On or off |
| **Announcement Interval** | How often the position is announced | 20 to 90 seconds |
| **Announcement Language** | Language of the announcement | English, Español, Français, or Hebrew |
| **Ring Strategy** | How calls are offered to agents | See the next table |
| **Agent Wrap-up time** | Time after a call before the agent gets the next one | 0 or more seconds |
| **Ring each agent for** | How long each agent rings before the next try | 15 seconds or more, default 30 |

## Ring strategies

| Ring strategy | How calls ring |
|---|---|
| **Ring All** | Every available agent rings at once. The first to answer takes the call. |
| **Round Robin** | Calls rotate between agents. This is the default. |
| **In Order** | Agents ring one by one, always starting from the top of the ring order. |
| **Least Talk Time** | The agent with the least talk time rings first. |
| **Least Number of Calls** | The agent who has taken the fewest calls rings first. |
| **By Agent Skill & Order** | Agents ring in sequence by their place in the ring order. |
| **Random** | A random available agent rings. |
| **Ring Progressively** | Agents are added to the ringing step by step. |

<Tip>
  Use **Ring All** for small teams where speed matters most. Use **Round Robin** or **Least Number of Calls** to spread work evenly across a larger team.
</Tip>

## Add agents and set the ring order

<Steps>
  <Step title="Open Manage Agents">
    On the queue card, open the actions menu and select **Manage Agents**.
  </Step>
  <Step title="Pick the members">
    Use **Search Members** to find people and select the members who should take calls from this queue.
  </Step>
  <Step title="Set the ring order">
    When two or more agents are selected, drag them in **Ring order** to set who rings first, second, and so on.
  </Step>
  <Step title="Save">
    Select the save button, for example **Save 3 agents**, to apply the changes. Newly added agents are logged in to the queue at their place in the order.
  </Step>
</Steps>

## Set a failover

A failover decides where calls go when the queue has no available agents. On the queue card, open the actions menu and select **Failover**. If the queue has a failover number, its call flow opens in the editor so you can change timeouts, voicemail, and other fallback steps. If not, TalkChief shows **No failover number is configured for this queue.**

## Manage a queue

From the queue card's actions menu you can also:

- **Edit Queue** to change any setting, then select **Update Queue Settings**
- **Change Color** to make the queue easy to spot
- **Delete Queue**, after you type the queue's name to confirm

## What agents see

Agents see their queues in their own workspace under **Queues**. The **My queues** page lists the queues they belong to and each queue's ring strategy. It does not show an agent's live login or break state.

## FAQ

<AccordionGroup>
  <Accordion title="Why is the Create Queue button disabled?">
    A required field is missing or out of range. Check that the name is unique, the extension is between 1 and 9999, the max wait time is between 30 and 300, and a **Time Zone** and **Media** file are selected.
  </Accordion>
  <Accordion title="How do I add agents while creating a queue?">
    Create the queue first. Then use **Manage Agents** on the queue card.
  </Accordion>
  <Accordion title="I get an error that I exceeded the number of allowed queues.">
    Your plan has a queue limit. Delete a queue you no longer use, or upgrade in **Settings** > **Plans**.
  </Accordion>
</AccordionGroup>
