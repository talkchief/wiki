An inbound agent answers calls that reach your TalkChief numbers. This page covers the agent's identity and how it sounds. You add documents, tools, and routing after that.

<Note>
You need a TalkChief admin or supervisor account and a free slot under your plan's AI agent limit. To place outbound calls, create a [campaign](/ai-agents/outbound-campaigns) instead.
</Note>

## Create the agent

<Steps>
  <Step title="Open Inbound agents">
    In the agents workspace, click **Inbound agents**, then **New inbound agent**.
  </Step>
  <Step title="Name the agent">
    In **Agent name**, enter a name your team will recognize, for example "Maya — customer care".
  </Step>
  <Step title="Create it">
    Optionally pick a role in **Start from a template**, such as **AI Receptionist**. Then click **Create inbound agent**. TalkChief creates the agent's own phone line and checks it. If the line cannot be verified, no agent is saved.
  </Step>
</Steps>

<Frame>
  ![The Create an inbound service agent dialog with the Start from a template picker, the Agent name field, and the AI agents usage note.](/images/docs/create-inbound-agent-dialog.png)
</Frame>

The agent opens on its canvas. The agent block sits at the top, with a group below it for **Language & voice**, **Knowledge**, and **Skills & tools**. Click the agent block or any block inside a group to edit it in the panel on the right. Use **\+** in a group to attach more, and drag blocks to rearrange them. A block marked **!** needs attention.

The header shows the phone line status, **Checks**, **Save changes**, and **Publish**. To switch to another agent, click the arrow next to the agent name in the breadcrumb. To see the blocks as a simple list instead of a canvas, click **List view**.

<Frame>
  ![The agent canvas for a fake Receptionist agent, with the Language & voice, Knowledge, and Skills & tools groups attached to the agent block.](/images/docs/agent-canvas.png)
</Frame>

<Tip>
The direction is fixed when you create the agent. If the job changes from answering to calling out, create a campaign.
</Tip>

## Set the persona

Click the agent block to open **Persona**.

Under **Agent template**, pick a **Template** and **Personality**, then click **Change template** (or **Use template** if the agent has none). This applies right away, so save any other persona edits first. Your edits stay on this agent; the template itself never changes. **Reset to template defaults** brings back the template's wording.

| Field | What to enter |
|---|---|
| **Agent name** | The name shown in your workspace |
| **Speaks as** | How the agent introduces itself, for example "Sara from Acme Dental" |
| **Role** | The job it does, for example "Front desk coordinator" |
| **Objective** (required) | One clear goal for every call |
| **Opening line** (required) | The first sentence the agent says when the call connects |
| **Business rules** | Your own **Do** and **Don't** rules. Type a rule and click **Add**; each rule saves as soon as you add it |
| **Never do** | Rules the agent must follow whatever the caller asks |

Then choose the service guardrails:

- **Disclose AI when asked**: if the caller asks whether this is AI or a person, the agent answers truthfully.
- **Honour do-not-call immediately**: an opt-out phrase records the request and ends the call.
- **Allow small talk**: the agent replies naturally to off-topic remarks before returning to the task.

<Warning>
Always set an **Opening line**. Without one, the caller hears silence until they speak, and many callers hang up.
</Warning>

## Choose language and voice

Click the **Language** or **Voice** block in the **Language & voice** group to open its panel.

<Steps>
  <Step title="Pick the language">
    In **Primary language**, choose **English**, **Arabic**, **Hebrew**, or **Auto-detect**.
  </Step>
  <Step title="Pick the dialect">
    In **Spoken dialect**, choose how the agent should sound. English offers American and British. Arabic offers Egyptian, Gulf / Najdi, Shami / Levantine, and Modern Standard. Hebrew offers Conversational Israeli.
  </Step>
  <Step title="Pick a voice">
    Choose the **Primary voice** or one of the **Secondary voices**. To see all 30 voices, open **More voice options (all 30)**.
  </Step>
  <Step title="Listen before you save">
    Use **Voice sample** to hear the selected voice in the selected language.
  </Step>
  <Step title="Pick a speaking tone">
    Choose one: **Friendly**, **Happy**, **Warm professional**, **Professional**, **Calm**, **Energetic**, **Direct**, or **Formal**.
  </Step>
</Steps>

## Save your changes

Click **Save changes** in the header. New calls use the saved settings right away. Knowledge and tool assignments save on their own as soon as you change them.

To undo unsaved edits, click **Discard** at the bottom of the panel.

A new agent starts as a **Draft**. When no item in **Checks** fails, click **Publish** to mark it **Published**. Warnings do not block publishing. A draft agent still answers the calls your call flow sends to it.

## Next steps

After the persona and voice, finish the setup in this order:

1. Grant documents in [Knowledge](/ai-agents/knowledge-base).
2. Turn on tools in [Skills & tools](/ai-agents/tools-and-integrations).
3. Grant [transfer destinations](/ai-agents/transfers).
4. [Add the agent to a call flow](/ai-agents/add-to-call-flow) and place a test call.

## FAQ

<AccordionGroup>
  <Accordion title="Which language should I choose if my callers speak several?">
    Choose **Auto-detect** to let the agent follow the caller. Pick a fixed language if most callers use one, because some features, such as spoken progress updates, need a primary language.
  </Accordion>
  <Accordion title="Can I change the voice later?">
    Yes. Change it in **Language & voice** and click **Save changes**. The next call uses the new voice.
  </Accordion>
  <Accordion title="How do I delete an agent?">
    Open the agent, click the more actions menu (**⋯**), then **Delete agent…**. TalkChief disconnects its phone line first. Existing call reports and transcripts stay available. If a call flow still uses the agent, remove that step first.
  </Accordion>
</AccordionGroup>
